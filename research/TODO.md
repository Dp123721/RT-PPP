## 建议目录规划

```text
research/
|-- configs/                 # 可复用配置模板
|-- schemas/                 # 输入、配置和结果 JSON Schema
|-- src/rtppp_analysis/      # 独立 Python 包
|-- tests/                   # 单元、解析器和端到端测试
|-- datasets/                # 数据登记表；不直接提交大型原始数据
|-- notebooks/               # 只做探索和复核，不承载唯一算法实现
|-- workspace/
|   |-- raw/                 # 原始数据，只读
|   |-- intermediate/        # 标准化及缓存数据
|   |-- results/             # 机器可读分析结果
|   |-- figures/             # 发布图件
|   |-- reports/             # HTML/PDF 报告
|   `-- manifests/           # 配置、输入哈希和环境记录
|-- README.md
|-- TODO.md
`-- pyproject.toml
```

大型数据和运行产物默认不进入 Git；Git 中只保留登记表、配置、Schema、小型回归样本和代码。
